CRAFTERWARS LEVEL 43

Standalone copy of Level 43 (XLIII) from Wholy's 100 Parkour
Stages / CrafterWars Parkour
https://www.planetminecraft.com/project/100-parkour-stage/
Please credit Wholy for the original map.

INSTALL
Extract this ZIP. Put the "CrafterWars - Level 43" folder directly in your
Minecraft saves folder. Launch Java Edition 1.8.9 and select 
"CrafterWars - Level 43" in Singleplayer.

PLAY
You start outside the level, facing the entrance.
Adventure mode, Peaceful difficulty. Cheats are enabled for practice.
Press the wooden button at the finish to collect your completion reward
and return to the entrance. Death also respawns you at the entrance.

PRACTICE / RESET
/kill returns you to the saved entrance respawn with fresh health.
/tp @p -40.5 4 250.5 90 0 returns you immediately (without resetting health).
Re-extract a fresh copy for a complete reset of the world and inventory.
